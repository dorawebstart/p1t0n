## 3. Data scientist — Крупіца Єгор

**Мета:** чесна гармонізація з виміряною точністю — це наш головний аргумент для Validity.

1. **Зараз, на даних Миколи (Україна).** Помісячні кількості за сенсором і супутником.
2. **Гармонізація v1 (до 18:00):**
   - коефіцієнт `k` = SNPP / Aqua для кожного місяця року, навчання на 2012–2020;
   - окремо Terra → SNPP тим самим способом;
   - гармонізований ряд для 2000–2011 = MODIS × `k`; для 2012+ — SNPP;
   - перевірка на 2021–2025: MAE, R² і графік «до / після» (хибний стрибок 2012 зник).
3. **Місток NOAA-20 → SNPP** на 2018–2025 — для 2026 року.
4. **`calendar` для України** з `median_count` і `anomaly` (z-score відносно медіани місяця). Передати капітанові до 20:00.
5. **Світ (15.11 до 11:00):** ті самі кроки на `grid_monthly`, коефіцієнти за широтними поясами (напр. по 10°). Метрики окремо «світ» і «Україна».
6. `metrics.json` з полем `notes`: обмеження (хмари, ранковий проліт Terra, проміжки MODIS у тропіках, NRT для 2026).

**Готово, коли:** є `grid_harmonized`, `calendar`, `metrics.json`, графік «до / після» для слайда і два речення про метод простою англійською.
