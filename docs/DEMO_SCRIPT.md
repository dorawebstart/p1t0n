## Календар — що натискати

1. **Region → Ukraine.** «Рядки — роки, стовпці — місяці. Колір — кількість пожеж у шкалі VIIRS.»
2. **Клік на клітинку** — серпень 2008 (z ≈ 3,7) або квітень 2005 (z ≈ 2,8). Справа: значення, медіана місяця, z-оцінка, діапазон 25–75 %. «Квітень і серпень — піки сезону; цей місяць значно вище звичного.»
3. **Перемикач Harmonized → MODIS → VIIRS (SNPP).** «Сирий MODIS — увесь ряд у рази нижчий; сирий VIIRS — порожньо до 2012. Гармонізований — один суцільний ряд у шкалі VIIRS.» Це найсильніший момент: видно, навіщо гармонізація.
4. **Anomalies only.** «Обведені — місяці, де z > 2: незвично сильне горіння для цієї зони.»
5. **Region → область** (напр. Kherson Oblast), потім **→ World або країну** (Brazil, Australia). «Той самий метод для будь-якої країни світу: 228 країн.»
6. **Download CSV / Download PNG.** «Дані й картинку можна забрати — це просили в завданні.»

## Можливі питання журі — короткі відповіді

- **Чому не NOAA-20 як еталон?** Найдовше перекриття з MODIS — у Suomi NPP (2012–2025). NOAA-20 приєднуємо через місток: прилади однакові, коефіцієнт ≈ 1.
- **Чому коефіцієнти за місяцями?** Відношення змінюється від ~4 до ~13 протягом року; один коефіцієнт дає велику сезонну похибку.
- **Чому WAPE клітинок 62 %, а зони — 14 %?** У клітинці 0,25° за місяць одиниці точок, шум ≈ 1/√N. Тому календар — для зон.
- **Це прогноз?** Ні. Діапазон 25–75 % — статистика минулих років для цього місяця.
- **Причини аномалій?** Ми показуємо аномалії режиму горіння, а не причини — для цього потрібні інші дані.
- **Де ШІ?** Допомагав писати код (Claude, Gemini); ідея, вибір методу й висновки — наші. Позначено в коді й `docs/SI_USAGE_LOG.md`.
